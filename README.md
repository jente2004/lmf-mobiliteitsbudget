# LMF Mobiliteitsbudget

Demo webtool voor het Belgische mobiliteitsbudget, gebouwd in de stijl van het LMF-logo.

## Functies

- **Dashboard** – Stand van zaken van je aanvraag (ingediend → in behandeling → afgerond)
- **Aanvraag** – Indienen en wijzigen van de verdeling over de drie pijlers
- **Informatietablad** – Wetgeving, bedragen 2026, voorwaarden en voorwaarden
- **LMF Assistent** – FAQ-chatbot (verwijst door naar HR bij onbekende vragen)

## Live demo

Open de GitHub Pages-versie of open gewoon `index.html` lokaal in de browser.

Repo: https://github.com/jente2004/lmf-mobiliteitsbudget

## Technologie

Pure HTML + CSS + JavaScript (geen build-stap, geen backend).  
Data wordt bewaard in `localStorage` van de browser.

## Kleuren (logo-stijl)

- Maroon: `#5C1A1B`
- Zachte roze achtergrond: `#FDF2F2`
- Accenten en kaarten in wit / lichtroze

## Opmerkingen

Dit is een **demo**. In productie zou de status door HR worden bijgewerkt en zou er authenticatie + een echte backend nodig zijn.
